# 📝 React Notes App

A simple and responsive notes-taking application built with **React.js** and **Tailwind CSS**. Users can write thoughts, save notes, delete notes and view them instantly with a clean and modern UI.

---

## 🚀 Features

- Add notes with heading and details 
- Delete notes 
- Beautiful glassmorphic UI  
- Fully responsive layout  
- React Hooks for state management  
- Fast and lightweight  

---

## 🛠️ Technologies Used

- React.js  
- Tailwind CSS  
- JavaScript (ES6+)  

---
